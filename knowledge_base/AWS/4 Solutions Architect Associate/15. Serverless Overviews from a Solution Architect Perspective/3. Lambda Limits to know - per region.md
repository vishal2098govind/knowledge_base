## Execution
- Memory - 128 MB to 10GB (1 MB increments)
- Max execution time : 15 minutes or 900 seconds
- Environment variables - 4KB
- Disk capacity in "function container" (in /tmp): 512 MB to 10GB
- Concurrency executions: 1000 (can be increased on request)

## Deployment
- Lambda function deployment size - compressed .ip : 50 MB
- Size of uncompressed deployment (code + dependencies): 250 MB
- Can use /tmp directory to load other files at startup
- Size of env variables: 4 KB

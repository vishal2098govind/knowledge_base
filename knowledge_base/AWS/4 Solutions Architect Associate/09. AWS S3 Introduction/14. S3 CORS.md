- CORS - Cross-Origin Resource Sharing
- Origin = scheme (protocol) + host (domain) + port
	- example: https://www.example.com (implied port is port is 443 for HTTPS, 80 for HTTP)
		- scheme = http
		- host = www.example.com
		- port = 443
- CORS is a web browser based mechanism of security to allow requests to other origins while visiting the main origin
- Same origin: http://example.com/app1 and http://example.com/app2
- Cross or different origin: http://www.example.com and http://other.example.com
- If our web browser is visiting one website and supposed to make a request to another website as part of request scheme, then these requests will not be fulfilled, unless the other origin allows the request from this origin using the CORS headers (example: **Access-Control-Allow-Origin**)

- For audit purpose, we want to log all access to S3 buckets
- Any request made to S3, from any account, authorized or denied, will be logged into another S3 bucket
- That data can be analyzed using some data analysis tools such as Athena
- The target logging bucket must be in the same AWS region
- Do not set logging bucket to be monitored bucket
- It will create logging loop, and bucket will grow exponentially

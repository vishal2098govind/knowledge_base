FIFO = First-In-First-Out **ordering** of messages in the queue

Messages are consumed in same order as they are produced

This is a guarantee of FIFO queue but this is not true for just a regular SQS queue. Messages can be received out of order.

Since we have ordering guarantee, we have limited throughput 
- of 300 msg/s without batching
- of 3000 msg/s with batching

**Exactly-once** send capability
- by removing duplicates using **Deduplication ID**

Messages are processed in order by consumer

Ordering guarantee is at **message group ID level**
- All messages in same group are ordered
- Message Group ID is a mandatory parameter

A FIFO SQS queue name must end with ".fifo" suffix or else it will not have ability to create FIFO queue

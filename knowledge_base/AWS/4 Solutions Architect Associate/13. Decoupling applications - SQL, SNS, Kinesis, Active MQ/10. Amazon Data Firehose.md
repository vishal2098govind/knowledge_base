Amazon Data Firehose was used to be called "Kinesis Data Firehose"

It's a fully managed service

Supported destinations:
- Amazon Redshift, S3, Amazon OpenSearch Service
- 3rd Party destinations: Splunk / MongoDB / Datadog / NewRelic 
- Custom HTTP Endpoint

Automatic Scaling, server-less, pay for what we use
**Near Real-Time** with buffering capability based on size or time
Supports CSV, JSON, Parquet, Avro, Raw Text, Binary Data
Conversions to Parquet, ORC, compressions with gzip or snappy
Custom Data Transformations using AWS Lambda (ex: CSV to JSON)

## Kinesis Data Stream vs Amazon Data Firehose
### Kinesis Data Streams
- Streaming Data Collection
- Producer and Consumer code to be written
- Real-time
- Provisioned or On-demand mode
- Data Storage up to 365 days
- Replay Capability

### Amazon Data Firehose
- Load streaming data into S3 or Redshift or OpenSearch or 3rd Party or Custom HTTP endpoint
- Fully managed
- Near real-time
- Automatic scaling
- No data storage
- Doesn't support replay capability

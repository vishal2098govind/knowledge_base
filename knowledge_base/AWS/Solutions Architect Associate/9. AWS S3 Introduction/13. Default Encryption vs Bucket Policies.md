- By default, now all buckets are having a default encryption of SSE-S3
- We can force encryption by using a bucket policy to refuse any API call to put an S3 object without correct encryption headers
![[Pasted image 20260530165114.png]]
- the left bucket policy denies any s3:PutObject unless the encryption header **`s3:x-amz-server-side-encryption`** set as **"`aws:kms`"**
- the right bucket policy denies any s3:PutObject if the customer side algorithm is not mentioned (`Null`) in the encryption header `s3:x-amz-server-side-encryption-customer-algorithm` in case of SSE-C
- Bucket policies can also force a way to have encryption in buckets
- Bucket policies are always going to be evaluated before default encryption settings

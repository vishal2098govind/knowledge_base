- Protects unintended deletes
- Easy roll back to previous version
- any file not versioned prior to enabling versioning will have version = "null"
- **suspending versioning does not delete previous versions**
- During deletion of objects after versioning is enabled, deletion adds a delete marker to the underlying object.
- To undo delete, delete the underlying delete marker
- On deletion of a versioned object, we can still find that object if we enable show versions switch, with a delete marker on the latest version of the object

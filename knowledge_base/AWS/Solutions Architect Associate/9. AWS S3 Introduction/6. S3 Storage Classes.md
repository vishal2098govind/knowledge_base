### Classes:
- Standard - General Purpose
- Infrequent Access (IA)
	- Standard IA
	- One Zone IA
- Glacier 
	- Instant Retrieval
	- Flexible Retrieval
	- Deep Archive
- Intelligent Tiering

Can move between classes manually or using S3 lifecycle configurations

### S3 Durability and Availability
- High durability - 11 9's i.e. 99.999999999 of objects across multiple AZ
- i.e. if we store 10,000,000 (10 M) objects with S3, we can on average expect to incur a loss of single object once every 10,000 years
- quite durable
- Durability is **same for all storage classes** in S3

- Availability measures how readily available a service is
- Varies **depending on storage class**
- E.g. S3 standard -> 99.99 availability -> not available 53 minutes a year


#### S3 Standard - General Purpose
- 99.99% availability
- Used for frequently accessed data
- Low latency and high throughput
- Sustain 2 concurrent facility failures

- Use cases: Big data analytics, mobile/gaming applications, content distribution

#### Infrequent Access
- for data that is less frequently accessed 
- but requires rapid access when needed
- lower cost than standard
- **Standard - IA**
	- 99.9% available
	- Use case: Disaster recovery, backups
- **One Zone - IA**
	- High durability (11 9's) in single AZ
	- data lost when AZ is destroyed
	- 99.5% Availability
	- Use case: Storing secondary backup copies of on-premise data, or **data u can recreate**

#### Glacier Storage
Low-cost object storage meant for archiving or backup
Pricing: price for storage + object retrieval cost
- **Instant Retrieval**
	- Millisecond retrieval, great for data access once a quarter
	- Minimum storage duration of 90 days
- **Flexible Retrieval (formerly S3 Glacier)**
	- **Expedited** - retrieval speed - 1 to 5 minutes
	- **Standard** - 3 to 5 hours
	- **Bulk** - 5 to 12 hours
	- Minimum storage duration of 90 days
- **Deep Archive**
	- **Standard** - 12 hours
	- **Bulk** - 48 hours
	- Minimum storage duration of 180 days

#### Intelligent Tiering
- monthly monitoring and auto-tiering fee
- Moves objects automatically between access tiers based on usage
- There're no retrieval charges in S3 Intelligent-Tiering

- **Tiers**:
	- Frequent Access Tier (automatic): default tier
	- Infrequent Access Tier (automatic): objects not accessed for 30 days
	- Archive Instant Access Tier (automatic): 90 days
	- Archive Access Tier (optional): 90 to 700+ days (configurable)
	- Deep Archive Access Tier (optional): 180 to 700+ (configurable)

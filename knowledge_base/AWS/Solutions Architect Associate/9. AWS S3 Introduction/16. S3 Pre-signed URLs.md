- Can be generated using CLI or SDK or console
- URL Expiration
	- Console - up to 12 hours
	- AWS CLI - up to 168 hours
- When generate a pre-signed URL, the user will get that URL which will inherit permissions of the user that generated that URL for a GET or a PUT.
- to give access to someone outside of AWS, access to one file, without making the file public
- Use-case: temporary access to one specific file for download or even for upload
- Examples
	- Allow only logged-in users to download a premium video from your S3 bucket
	-  Allow an ever-changing list of users to download files by generating URLs dynamically
	- Allow temporarily a user to upload a file to a precise location in your S3 bucket

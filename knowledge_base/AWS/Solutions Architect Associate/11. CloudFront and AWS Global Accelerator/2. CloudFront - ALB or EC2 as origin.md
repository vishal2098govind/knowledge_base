## Using VPC origins (New and recommended way)
- Allows deliver content from application hosted in VPC private subnets
- without needing to expose them to internet
- Deliver traffic to private:
	- Application Load Balancer
	- Network Load Balancer
	- EC2 instances
![[Pasted image 20260530202258.png]]
- From a network perspective, this is one of the most secure way of doing the setup because applications are still hosted privately internally, and then we choose what to expose through CloudFront

## Using Public Network (Old way)
- Old method before VPC origin feature existed
- Need to make sure to change security group of EC2 instances or ALB to allow all public IPs of the CloudFront edge locations
- **Tedious** - to keep track of all public IPs of all edge locations
- **Risk** - if someone changes security group of ALB or EC2, the ALB or EC2s are public to more than CloudFront distribution

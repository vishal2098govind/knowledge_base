Give users an identity to interact with our web or mobile application

## Cognito User Pool
- Sign in functionality for app users
- Integrate with API Gateway and ALB

## Cognito Identity Pools
- Federated identity
- Provide termporary AWS credentials to users so they can access AWS resources directly

### Cognito vs IAM
- Cognito is for web and mobile app users who sit outside of AWS

## Cognition User Pools (CUP) – User Features
- Creates a serverless database of users for our web and mobile application
- Simple login: username (or email) / password combination
- Password reset
- Email and phone number verification
- MFA
- Federated identities: users from Facebook, Google, SAML...
- CUP integrates with **API Gateway** and **ALB**
- It's a responsibility that we've moved from our backend to actual piece that is going to balance load for backend

## Cognito Identity Pools (Federated Identities)
- Get identities for users so temporary AWS credentials
- Users source can be Congino User pools, 3rd party logins, etc
- Users can then access AWS services directly or through API Gateway
- IAM Policies applied to credentials are defined in Cognito
- They can be customized based on user_id for fine grained control
- Default IAM roles for authenticated and guest users

- We will see how we can orchestrate stuff between different services using middleware
- When we start deploying multiple applications, they will inevitably need to communicate with one another
- There are two patterns of application communication:
	- Synchronous Communications (application to application)
	- Asynchronous Communications or Event based (application to queue to application)
- Synchronous between applications can be problematic if there are sudden spikes of traffic
- What if you need to suddenly encode 1000 videos but usually it’s 10?

- In that case, it's better **decouple** your applications and have the decoupling layer scale for you:
	- using **SQS**: queue model
	- using **SNS**: pub/sub model
	- using **Kinesis**: real-time streaming model
- These services can scale independently from our application

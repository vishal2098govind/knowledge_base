**Amazon CloudWatch** has available Amazon EC2 Metrics for you to use for monitoring 
- CPU utilization
- Network utilization
- Disk performance
- Disk Reads/Writes. 

**memory and disk utilization** metrics are **not available** in the default CloudWatch configuration

In case you need to monitor the below items, you need to prepare a **custom metric** using a Perl or other shell script, as there are **no ready-to-use** metrics for the following:
- Memory utilization
- Disk swap utilization
- Disk space utilization
- Page file utilization
- Log collection

**Enhanced Monitoring** is only a feature of Amazon RDS. By default, Enhanced Monitoring metrics are only stored for 30 days in the CloudWatch Logs.

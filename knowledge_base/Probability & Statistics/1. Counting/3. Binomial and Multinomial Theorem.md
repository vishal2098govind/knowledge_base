## Binomial Theorem: $(X+Y)^n$
- $(X+Y)^2=X^2+Y^2+2XY$

### Interpretation of Binomial Theorem
- We've 2 containers, both containers have X and Y, i.e. each container has x, y
- Now, we've to take one object out of each container
	- T1: Take x or y from container 1
		- T11: Take x from container 1
		- **OR** T12: Take y from container 2 #rule-of-sum 
		- i.e. $(X+Y)$
	- **and then** T2: Take x or y from container 2 #rule-of-product
		- T21: Take x from container 1
		- **OR** T22: Take y from container 2
		- i.e. $(X+Y)$
	- i.e. $(X+Y)*(X+Y)$
	- $X^2+2XY+Y^2$
		- Either $X^2$: 
			- Take x from container 1
			- **and then** x from container 2 #rule-of-product 
		- **OR** $Y^2$ #rule-of-sum 
			- Take x from container 1
			- **and then** y from container 2 #rule-of-product 
		- **OR** XY
			- Take x from container 1
			- **and then** y from container 2 #rule-of-product 
		- **OR** YX
			- Take y from container 1
			- **and then** x  from container 2 #rule-of-product 
	- Now, we can also interpret $X^2+2XY+Y^2$ like:
		- Coefficient of $X^2$ = no.of ways we can select 1 x and 1 x from both containers = which is 1 way
		- Coefficient of $XY$ = no.of ways we can select 1 x and 1 y from both containers = which is 2 ways
			- x from container 1 and y from container 2
			- or y from container 1 and x from container 2
		- Coefficient of $X^2$ = no.of was we can select 1 y and 1 y from both containers = which is 1 way
	- Thus, similarly
		- $(X+Y)^3$ = $^3C_{3}X + ^3C_{2}X^2Y+^3C_{1}XY^2+^3C_{3}Y^3$
			- Coefficient of $X^3$ : no.of ways we can select 3 x's from 3 containers = $^3C_{3}$ way
			- Coefficient of $X^2Y$ : no.of ways we can select 2 x and 1 y from 3 containers = $^3C_2$ ways
			- Coefficient of $XY^2$ : no.of ways we can select 1 x and 2 y from 3 containers = $^3C_1$ ways
			- Coefficient of $Y^3$ : no.of ways we can select 3 y's from 3 containers = $^3C_{3}$ ways
		- $(X+Y)^5$ = $^5C_{5}X + ^5C_{4}X^4Y+^5C_{3}X^3Y^2+^5C_{3}X^2Y^3+^5C_{1}X^{1}Y^4+^5C_{5}Y^5$
			- Coefficient of $X^5$ : no.of ways we can select 5 x's from 5 containers = $^5C_{5}$ way
			- Coefficient of $X^4Y$ : no.of ways we can select 4 x and 1 y from 5 containers = $^5C_4$ ways
			- Coefficient of $X^3Y^{2}$ : no.of ways we can select 3 x and 2 y from 5 containers = $^5C_3*^2C_{1}$ ways
			- Coefficient of $X^2Y^{3}$ : no.of ways we can select 2 x and 3 y from 5 containers = $^5C_2*^4C_{4}$ ways
			- Coefficient of $XY^4$ : no.of ways we can select 1 x and 4 y from 5 containers = $^5C_1$ ways
			- Coefficient of $Y^5$ : no.of ways we can select 5 y's from 5 containers = $^5C_{5}$ ways
		- $(X+Y)^n = ^nC_{n}X^n+^{n}C_{n-1}X^{n-1}Y + ^nC_{n-2}X^{n-2}Y^2+\dots ^nC_{n-k}X^{n-k}Y^k+\dots  +^nC_{n}Y^n$
			- = $\sum^n_{k=0} (^nC_{n-k}X^{n-k}Y^{k})$, $^nC_{n-k}$ or $^nC_{k}$ is the binomial coefficient of $X^{n-k}Y^k$

### Binomial Theorem
- Sum of all binomial coefficients = $2^n$ for $(X+Y)^n$
	- $\sum_{k=0}^n(^nC_{k})$
	- For n=3: $^3C_{0}+^3C_{1}+^3C_{2}+^3C_{3}$ = 8
	- For n=4: $^4C_{0}+^4C_{1}+^4C_{2}+^4C_{3}+^4C_{4}$ = 16 
	- Thus, for n=n, just put x=1 and y=1, thus $(1+1)^n$ = $2^n$
	- Sum of all binomial coefficients can also be interpreted as:
		- there are n containers, each having x and y
		- from each container we can pick one of them in 2 ways i.e. either x or y
		- thus no.of ways of picking **any number of x's and any number y's** among n x's and n y's
			- T1: no.of ways to pick any no.of x and any no.of y's from container 1 = 2 (1 x and 0y's **OR** 0x's and 1y)
			- **and then** T2: no.of ways to pick any no.of x and any no.of y's  from container 2 = 2 (1 x and 0y's **OR** 0x's and 1y)
			- **and then** T3: no.of ways to pick any no.of x and any no.of y's  from container 2 = 2 (1 x and 0y's **OR** 0x's and 1y)
			- ... **and then** Tn: no.of ways to pick any no.of x and any no.of y's  from container n = 2 (1 x and 0y's **OR** 0x's and 1y)
			- = $2^n$
			- = Sum of all binomial coefficients as well


## Multinomial Theorem: $(X_{1}+X_{2}+\dots+X_{m})^n$
- $(X+Y+Z)^2$ = $(X+Y+Z)(X+Y+Z)$ => here we have 2 buckets/containers and each container has X, Y and Z
- $(X+Y+Z)^3$ = $(X+Y+Z)(X+Y+Z)(X+Y+Z)$ => here we have 3 buckets/containers and each container has X, Y and Z
	- $X^aY^bZ^c$
		- a+b+c = 3 and a,b,c>=0
		-  using #boxes-sticks  
			- 3 partitions => 2 sticks => 2 boxes
			- remaining boxes for 3, i.e. 3+2 = 5 boxes in total
			- thus, no.of ways we can select a, b, c such that we get a sum of 3 => $^5C_{2} = 10$
		- Thus $(X+Y+Z)^3$ has 10 terms
		- Coefficient of a term: #multinomial-coefficient
			- E.g. take $X^2Y$ => no.of ways of taking 2 Xs, 1Y and 0Z
				- Choose any two containers for X 
				- **and then** choose remaining container for Y #rule-of-product 
				- $^3C_{2}*^1C_{1}$
			- E.g. take $XYZ$ => no.of ways of taking 1 Xs, 1Y and 1Z
				- Choose any 1 container from available 3 containers for X 
				- **and then** choose 1 container **from remaining** 2 containers for Y #rule-of-product 
				- **and then** choose 1 container **from remaining** 1 container for Z
				- $^3C_{1}*^2C_{1}*^1C_{1}$
			- E.g. take $X^aY^bZ^c$ => no.of ways of taking a Xs, b Y's and c Z's
				- Choose any a containers from available 3 containers for X 
				- **and then** choose b containers **from remaining** (3-a) containers for Y #rule-of-product 
				- **and then** choose c container **from remaining** ((3-a)-b) container for Z
				- $^3C_{a}*^{(3-a)}C_{b}*^{(3-a)-b}C_{c}$
- $(X_{1}+X_{2}+X_{3}+X_{4}+\dots X_{m})^n$
	- n buckets, each bucket having $X_{1}, X_{2}, X_{3}, \dots X_{m}$
	- general term would look like: 
		- $X_{1}^{a_{1}}X_{2}^{a_{2}}\dots X_{m}^{a_{m}}$
		- $\sum_{i=1}^m a_{i}=n$
		- with coefficient: $^nC_{a_{1}}*^{n-a_{1}}C_{a_{2}}*^{(n-a_{1})-a_{2}}C_{a_{3}}*\dots*^\left( {n-\sum_{i=1}^{m-1} a_{i}} \right)C_{a_{m}}$
			- $\frac{n!}{a_{1}!*a_{2}!*a_{3}!*\dots*a_{m}!}$
			- This is popularly called $^nC_{a_{1},a_{2},a_{3},\dots ,a_{m}}=(^{n}_{a_{1}a_{2}a_{3}a_{4}\dots a_{m}})$
	- E.g.: In $(X_{1}+X_{2}+X_{3}+X_{4})^{10}$, find coefficient of $X_{1}^2X_{2}^3X_{3}^1X_{4}^4$ :
		- $^{10}C_{2}*^{8}*C_{3}*^5C_{1}*^4C_{4}$
		- aka: $^{10}C_{2,3,1,4}$
	- Thus $$(X_{1}+X_{2}+X_{3}+X_{4}+\dots X_{m})^n = \sum_{a_{1}+a_{2}+\dots a_{m}=n} (^{n}_{a_{1}a_{2}a_{3}a_{4}\dots a_{m}})\prod_{i=1}^{m} X_{i}^{a_{i}}$$
	- Multinomial Theorem is nothing combination of all possible expressions representing all possible ways to select $a_{1},a_{2},a_{3} \dots a_{m}$ such that $a_{1}+a_{2}+a_{3}+\dots+a_{m}=n$
	- Thus $$(X_{1}+X_{2}+X_{3}+X_{4}+\dots X_{m})^n=\sum_{a_{1}+a_{2}+\dots a_{m}=n}\frac{n!}{a_{1}!*a_{2}!*a_{3}!*\dots*a_{m}!}*\prod_{i=1}^{m} X_{i}$$
	- Sum of all coefficients of multinomial terms = $m^n$
		- Mathematical proof: put all $X_{i}$ =  1
		- Theoretical proof:
			- Multinomial expression represents there are n containers each containing m distinct objects
			- Sum of all coefficients means, all possible ways to select m objects
				- T1: no.of ways of picking any of m objects from container 1 = m (either $X_{1}$ **OR** $X_{2}$ **OR** $\dots$ **OR** $X_{m}$)
				- **and then** T2: no.of ways of picking any of m objects from container 2 = m
	- No.of multinomial terms
		- Multinomial terms are combination of all possible ways to **select n objects using m distinct objects with repetition**
			- powers of each of $X_{1}, X_{2}, \dots , X_{{m}}$ represent the no.of objects of such type are considered
			- no.of such terms can be found using the #boxes-sticks  
			- $a_{1}+a_{2}+a_{3}+\dots+a_{m}=n$
			- thus, 
				- we need $m$ partitions, i.e. $m-1$ sticks, i.e. $m-1$ boxes for sticks
				- remaining boxes should add up to $n$, thus $m-1+n$  boxes in total
				- thus, no.of ways of selecting $m-1$ sticks from $m-1+n$ boxes = $^{m-1+n}C_{m-1}$=$^{m-1+n}C_{n}$
				- Thus, there are $^{m+n-1}C_{n}$ terms in a multinomial expressions

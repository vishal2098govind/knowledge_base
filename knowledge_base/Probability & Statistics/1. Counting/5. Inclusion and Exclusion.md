- **How many positive integers <= 100 are non multiples of 2 or 3**
	- there are 100 positive integers which are <= 100
	- out of these 100, no.of positive integers which are divisible by 2 <= 100 
		- = no.of even numbers <= 100 = $\lfloor\frac{100}{2}\rfloor=50$
	- out of these 100, no.of positive integers which are divisible by 3 <= 100 
		- = $\lfloor\frac{100}{3}\rfloor=33$
	- out of these 100, no.of positive integers which are divisible by 2 and 3 both
		- = $\lfloor\frac{100}{LCM(2,3)=6}\rfloor=16$
	- out of these 100, no.of positive integers which are not divisible by 2 and 3 both
		- if we just do 100 - 50 - 33, we will remove those which are divisible by both 2 and 3 twice
		- thus add one more time the no.of numbers divisible by both 2 and 3
		- 100 - 50 - 33 + 16
		- **so, this is inclusion/exclusion, i.e. if we exclude something, we over-exclude and thus to compensate, we include those again which we over-excluded** 
			- Similar to $n(A \cup B) = n(A) + n(B) - n(A\cap B)$

## Principle of Inclusion-Exclusion
In general form, the principle of inclusion-exclusion states that for finite sets $A_{1}, A_{2}, A_{3}\dots A_{n}$
- $|A_{1}\cup A_{2}\cup A_{3}\cup\dots\cup A_{n}|$ = 
	- $|A_{1}|+|A_{2}|+\dots+|A_{n}|$
	- - $|A_{1}\cap A_{2}|+|A_{1}\cap A_{2}|+\dots+|A_{n-1}+A_{n}|$
	- + $|A_{1}\cap A_{2}\cap A_{3}|+|A_{1}\cap A_{2}\cap A_{4}|+\dots+|A_{n-2}\cap A_{n-1}+A_{n}|$
	- - take 4 at a time
	- + take 5 at a time
	- - take 6 at a time
	- ...
	- ... + $(-1)^{n-1}|A_{1}\cap A_{2}\cap\dots \cap A_{n}|$ (take all)
- In compact form: $$|\bigcup_{i=1}^nA_{i}| = \sum|A_{i}|- \sum_{1\leq i\leq j\leq n}|A_{i}\cap A_{j}|+\sum_{1\leq i\leq j\leq k\leq n}|A_{i}\cap A_{j}\cap A_{k}|- \dots\dots(-1)^{n-1}|\bigcap_{i=1}^{n}A_{i}|$$

- Question: **How many integral solutions does the following system of equations has?**
	- $x_{1}+x_{2}+x_{3}=10$  such that $0\leq x_{1}\leq{4}, 0\leq x_{2}\le{4}, 0\leq x_{3}\le{4}$
		- for $x_{1}\geq_{0}, x_{2}\geq_{0},x_{3}\geq_{0}$ we can solve using #boxes-sticks 
			- i.e. 3 partitions => 2 sticks => 2 boxes and 10 more boxes
			- => 10+2=12 boxes in total
			- thus $^{12}C_{2}$ no.of integral solutions 
			- but among these, we also **included** those for which $x_{i}>4, \forall i\in\{1, 2, 3\}$
			- thus we need to **exclude** those cases
			- thus, we need to exclude sets $S_{i}=x_{i}\geq{5}, \forall i\in\{1,2,3\}$, this we already know how to solve using #boxes-sticks 
			- thus, **exclude** no.of solutions in: 
				- $a_{1}+5+x_{2}+x_{3}={10}$ to calculate no.of solutions with $x_{1}\geq{5}$ = $^7C_{2}$
				- $x_{1}+a_{2}+5+x_{3}=10$ to calculate no.of solutions with $x_{2}\geq{5}$ = $^7C_{2}$
				- $x_{1}+x_{2}+x_{3}+5=10$ to calculate no.of solutions with $x_{3}\geq{5}$ = $^7C_{2}$
				- thus, finally $^{12}C_{2} - ^{7}C_{2}-^{7}C_{2}-^{7}C_{2}$
				- but it's not done yet, as we have **over-excluded** so far. thus include again to compensate
					- $^{12}C_{2} - ^{7}C_{2}-^{7}C_{2}$ till this, we removed $x_{1}\geq{5}$ **AND** $x_{2}\geq{5}$ two times, thus we have to add them once
					- i.e. add case when $x_{1}\geq{5}$ **AND** $x_{2}\geq{5}$
						- i.e. no.of solutions for $a_{1}+5+a_{2}+5+x_{3}=10$ => $^{0+2}C_{2}=^2C_{2}=1$ i.e. there's only one solution for this
						- because both $x_{1}\geq_{5}$ and $x_{2}\geq5$ thus $x_{1}=5$ and $x_{2}=5$ and if both are 5, $x_{3}$ has to be 0, thus no other way, thus only 1 solution
					- similarly add case for $x_{2}\geq_{5}$ **AND** $x_{3}\geq_{5}$ = $^2C_{2}$ = 1 way
					- similarly add case for $x_{1}\geq_{5}$ **AND** $x_{3}\geq_{5}$ = $^2C_{2}$ = 1 way
					- and now so far 
						- we have excluded the case where all $x_i\geq_{5}$ 3 times
						- and also we have included the case where all $x_i\geq_{5}$ 3 times
						- thus, the case where all $x_i\geq_{5}$ is still present, which we have to **exclude** once more
							- no.of solutions for all $x_i\geq_{5}$ = 0 as it is not possible for all $x_i\geq_{5}$ and they sum to 10
			- thus final answer: $$^{12}C_{2} - ^{7}C_{2}-^{7}C_{2}-^{7}C_{2}+^2C_{2}+^2C_{2}+^2C_{2}-0$$
- Question: **How many integral solutions does the following system of equations has?**
	- $x_{1}+x_{2}=10$  such that $x_{1}\geq{0}, 0\leq x_{2}\le{6}$
		- first solve for $x_{1}+x_{2}=10$ such that $x_{1}\geq{0},x_{2}\geq0$ i.e. there are $^{11}C_{1}$
		- then remove the cases where $x_{2}>=7$
			- i.e. $x_{1}+a_{2}+7=10 \implies x_{1}+a_{2}=3$ i.e. there are $^4C_{1}$ solutions for this
			- thus solution: $^{11}C_{1}-^4C_{1}$
	- $x_{1}+x_{2}=15$  such that $0\leq x_{1}\leq{5}, 0\leq x_{2}\le{5}$
		- first solve for $x_{1}+x_{2}=15$ such that $x_{1}\geq{0},x_{2}\geq15$ i.e. there are $^{16}C_{1}$
		- remove the cases where $x_{1}>=6$
			- i.e. $x_{1}+a_{2}+6=15 \implies x_{1}+a_{2}=9$ i.e. there are $^{10}C_{1}$ solutions for this
			- thus solution far: $^{16}C_{1}-^10C_{1}$
		- remove the cases where $x_{2}>=6$
			- i.e. $x_{1}+a_{2}+6=15 \implies x_{1}+a_{2}=9$ i.e. there are $^{10}C_{1}$ solutions for this
			- thus solution far: $^{16}C_{1}-^{10}C_{1}-^{10}C_{1}$
		- Now, we have excluded solutions which have both $x_{1}\geq{6} \cap x_{2}\geq{6}$ twice, thus include once
			- i.e. $a_{1}+6+a_{2}+6=15\implies a_{1}+a_{2}=3$ i.e. there are $^4C_{1}$ solutions for this
			- so final solution: $^{16}C_{1}-^{10}C_{1}-^{10}C_{1}+^4C_{1}=0$
- Question: **In how many permutations of 26 small case english alphabets do not have "cat", "dog" or "mule" as a substring?**
	- all possible words: $26!$
		- out of these **remove** the cases where there are "cat" in substring
			- now we have 26-3+1 = 24 objects => 24!
			- -24!

			- now we have 26-4+1 = 23 objects => 23!
			- -23!
		- we have removed the case where both "cat" and "dog" are present twice, thus **include** once more
			- $(26-6+2)!$=22!
			- $+22!$
		- we have removed the case where both "cat" and "mule" are present twice, thus **include** once more
			- (26-7+2)!=21!

## Permutation
A permutation of a set is an **arrangement of its members** into a sequence or a **linear order**

Factorial: no.of ways to arrange n objects in a row
Permutation: no.of ways to arrange r objects out of n objects in a row: $^nP_{r}$
**Permutation** means **arrangement**
**Combination** means **selection**

- Full vs Partial Permutation: 
	- Full: 
		- No.of ways to arrange n objects out of n objects
		- = $n!$ = $^nP_{n}$
	- Partial:
		- No.of ways to arrange r objects out of n objects
		- = $^nP_{r}$ (read as n permute r) = $n * (n-1) * (n-2) * \dots. * (n-(r-1))$
		- without repetition or by default is nothing is mentioned about repetition, **repetition is not allowed**
			- i.e. all objects are unique, cannot use same object more than one to arrange

### Examples
- No.of ways to arrange 3 objects out of 5 distinct objects
- Solution: (Derivation)
	-  Let objects be A, B, C, D, E
	- possible arrangements of 3: 
		- ABC
		- BCA
		- ACB
		- ... lot of such
		- We have 3 places to fill. 
			- for first place, we have 5 options
			- for second place, we have 4 options #rule-of-product 
			- for third place we have 3 options
			- How #rule-of-product :
				- T1: Fill first place using any 5
				- **and then** T2: Fill second place using any 4 remaining
				- **and then** T3: Fill third place using any 3 remaining
			- Thus:
				- No.of ways of arranging 3 objects out of 5 is : $5 * 4 * 3$ = this is nothing but $^5P_{3}$
				- No.of ways of arranging r objects out of n is : $n * (n-1) * (n-2) * \dots. * (n-(r-1))$ = this is nothing but $^nP_{r}$
				- $^nP_{r} = \frac{n!}{(n-r)!}$
				- But, this formula way need not be preferred, rather can prefer the proof way:
					- E.g.: $^7P_{3}=7*6*5$ this is simpler than finding $\frac{7!}{4!}=\frac{5040}{24}$, 
					- i.e. starting from $n$, keep multiplying backward until u reach $n-(r-1)$ or reach $r$ numbers in the product expression


- Question: Number of 3 letter words with/without meaning that can be formed using "PARTY"
- Solution: $^5P_{3}=5*4*3$

- Question: In how many ways can the word CLIMATE be arranged
- Solution: $7!$ i.e. full permutation
- Question: In how many ways can the word BEAKER be arranged (there are **repeating items**)
- Solution: $\frac{6!}{2!}$, i.e. E is repeated 2 times
- Question: In how many ways can the word AABBBCD be arranged (there are **repeating items**)
- Solution: $\frac{7!}{2!*3!}$

- Question: Number of permutations of the word CLIMATE such that all consonants occur together
- Solution:
	- Consonants: CLMT, Vowels: IAE, 
	- thus : <consonants/> I A E => 4 letters =4!
	- for each word, there CLMT can be arranged in 4! ways
	- thus ans: $4!*4!$ #rule-of-product 
		- T: arrange letters in CLIMATE such that CLMT appear together
			- T1: consider $G_{1}$ = CLMT (group-1), and arrange $G_{1}$IAE in all possible ways
			- **and then** T2: arrange CLMT in $G_{1}$ in each of the arrangements (obtained in T1), in all possible ways


- Question: Number of permutations of the word CLIMATE such that all consonants occur together and all vowels occur together
- Solution:
	- Consonants: CLMT, Vowels: IAE, 
	- thus : <consonants/> <vowels/> => 2 letters =2!
	- for each word, 
		- CLMT can be arranged in 4! ways 
		- and IAE can be arranged in 3!
	- thus, $2!*4!*3!$

- Question: Number of permutations of the word CHEETAH such that all vowels occur together
- Solution:
	- Consonants: CHTH, Vowels: EEA, 
	- thus : <vowels/> CHTH => 5 letters = $\frac{5!}{2! }$
	- for each word, 
		- and EEA can be arranged in $\frac{3!}{2!}$
	- thus, $\left( \frac{5!}{2!} \right)*\left( \frac{3!}{2!} \right)$

- Question: Number of permutations of the word CHEETAH such that all consonants occur together and all vowels occur together
- Solution:
	- Consonants: CHTH, Vowels: EEA, 
	- thus : <consonants/> <vowels/> => 2 letters =2!
	- for each word, 
		- CHTH can be arranged in $\frac{4!}{2!}$ ways 
		- and EEA can be arranged in $\frac{3!}{2!}$
	- thus, $2!*\left( \frac{4!}{2!} \right)*\left( \frac{3!}{2!} \right)$ 

- Question: Number of permutations of the word CHEETAH such that vowels and consonants are in alternate places
- Solution:
	- Consonants (c): CHTH, Vowels (v): EEA, 
	- Possibilities: 
		- c v c v c v c
		- v c v c v c c => this is not valid as c c are coming together
	- ans: $\left( \frac{4!}{2!} \right)*\left( \frac{3!}{2!} \right)$ #rule-of-product 
		- T1: arrange c = $\left( \frac{4!}{2!} \right)$
		- **and then** T2: arrange v = $\left( \frac{3!}{2!} \right)$

## Combination
A combination is a set of **selection of members**, where **order of selection is NOT important**
In combination, select items in any order
**Permutation**: no.of ways to **arrange** r objects out of n objects in a row: $^nP_{r}$
**Combination**: no.of ways to **select** r objects out of n objects in a row, without any particular order: $^nC_{r}$

Example:
- among ABC, 
	- **select or combine or choose** 2
		- AB in any order
		- BC in any order
		- AC in any order
	- **arrange** 2
		- AB, BA
		- BC, CB
		- AC, CA

- Here, every **selection** is repeating $r!$ times in case of permutation
- Thus, $^nP_{r}$ = $^nC_{r} * r!$
- $^n{C}_{r}$ means **n choose r**
### Axioms in Combinations:
#### Combination as Recurrence
- $^nC_{r}$  =  $^{n-1}C_{r} + ^{n-1}C_{r-1}$ (pascal's triangle)
	- Computer engineers use this a lot because, 
		- if we want to calculate and **store in memory** $^nC_{r}$ for all possible values of $n$ and $r$, i.e. 
			- $^1C_{1}, ^2C_{1}, ^2C_{2}, ^2C_{3}, ^4C_{1}, ^4C_{2}, ^4C_{3}$ and so on ...  upto say $^7C_{7}$
		- Then, instead of writing formula of $^nC_{r}=\frac{n!}{(n-r)!r!}$, we can use the recurrence formula
		- if we already have $^6C_{1}$ and $^6C_{2}$ in memory, we can find $^7C_{2}=^6C_{1}+^6C_{2}$
	- Proofs:
		- Intuitive proof ( #rule-of-sum ):
			- $^6C_{3}$ : No.of ways of selecting 3 items out of 6 items
				- T1: Either Select 1st item
					- Now we are left with no.of ways of selecting 2 items out of 5 = $^5C_{2}$
				- **OR** T2: Leave 1st item
					- Now we are left with no.of ways of selecting 3 items out of 5 = $^5C_{3}$
- $^nC_{0}$ = 1, $^nC_{n}$ = 1
- Pascal's triangle is symmetric.  $^nC_{r} = ^nC_{n-r}$
	- This formula is popularly called k-selection = k-rejection i.e. $^nC_{k} = ^nC_{n-k}$ 
	- thus, $^nC_{k}$ is no.of ways of selecting k items out of n items
		- and is also equal to no.of ways of rejecting k items out of n items, i.e. no.of ways of selecting $n-k$ items, which is = $^nC_{n-k}$

### Examples
- Question: Total number of matches played in CWC 2023. There are 10 teams
	- Each team plays every other team once in league stages
	- 3 knockout matches, 2 semifinals and 1 final
- Solution:
	- $^{10}C_{2}$ + 3 + 2 + 1

- Question: 16 questions in total. 2 sets Set-A, Set-B
	- 2 questions at least from each set
	- answer 5 questions in total
	- find no.of ways to answer 5 questions
- Solution:
	- T: find no.of ways to answer 5 questions
		- **Either** T1: 
			- select 2 from Set-A
			- **and then** select 3 from Set-B
			- = $^8C_{2}*^8C_{3}$ #rule-of-product 
		- **OR** T2: 
			- select 3 from Set-A
			- **and then** select 2 from Set-B
			- = $^8C_{3}*^8C_{2}$ #rule-of-product 
	- Thus, total no.of ways = $^8C_{2}*^8C_{3} + ^8C_{3}*^8C_{2}$ #rule-of-sum 

- Question: No.of diagonals in an n-sided polynomial
- Solution:
	-   $^nC_{2}-n$, subtracting n to exclude adjacent

## P & C With Repetition
### Combination with Repetition
#combination-with-repetition
- Repetition means each object can be selected more than once and any number of items, i.e. each item has $\infty$ supply
- In a set of n elements, any selection of r elements, where **each object can be selected any number of times**


Example:
- No.of ways of **selecting or choosing** 3 letters from a, b, c, d with repetition allowed
	- aaa, aab, aac, aad
	- abb, abc, abd
	- acc, acd,
	- add
	- bbb, bbc, bbd
	- bcc, bcd, 
	- bdd
	- ccc, ccd, 
	- cdd
	- ddd
- let $n_{a}, n_{b}, n_{c}, n_{d}$ be number of a's, b's, c's and d's respectively
- we know that $\sum_{i=a}^d n_{i}$ should be 3
- Thus, any solution to this system of equation $n_{a}+n_{b}+n_{c}+n_{d}=3$, will be a selection
	- Thus, number of solutions to this equation = no.of ways of selecting 3 among a, b, c, d with repetition
- thus, we can do it by
	- T1: 
		- $n_{a}=3$ = $^3C_{3}$
		- **and then** $n_{b} = 0$ = $^3C_{0}$
		- **and then** $n_{c}=0$ = $^3C_{0}$
		- **and then** $n_{d}=0$ = $^3C_{0}$ #rule-of-product 
		- = $^3C_{3}*^3C_{0}*^3C_{0}*^3C_{0}$
	- **OR** T2:  #rule-of-sum 
		- $n_{a}=2$ = $^3C_{2}$
		- **and then** $n_{b} = 1$
		- **and then** $n_{c}=0$
		- **and then** $n_{d}=0$
		- = $^3C_{2}*^3C_{1}*^3C_{0}*^3C_{0}$
	- **OR** T3: 
		- $n_{a}=2$
		- **and then** $n_{b} = 0$
		- **and then** $n_{c}=1$
		- **and then** $n_{d}=0$
		- = $^3C_{2}*^3C_{0}*^3C_{1}*^3C_{0}$
	- and so on

- Mapping the solution with system of equations
	- E.g.: let $x+y=3$, with $x,y \geq 0$
		- Possible solutions: 
			- $x=3, y=0$,
			- $x=2, y=1$,
			- $x=1, y=2$,
			- $x=0, y=3$
			- i.e. 4 solutions possible
			- This can be mapped to the problem : we have 2 objects and we want to select 3 objects with repetition allowed
				- A, B are objects
				- AAA, AAB, ABB, BBB are the  only possible ways to select 3 objects
			- we can take 4 boxes and 1 sticks and number of ways to put 1 sticks on 4 boxes =$^4C_{1}$
	- 4 objects ABCD, select 3 with repetition allowed
		- Combinations:
			- AAA, AAB, AAC, AAD
			- ABB, ABC, ABD
			- ACC, ACD
			- ADD
			- BBB, BBC, BBD
			- BCC, BCD
			- BDD
			- CCC, CCD
			- CDD
			- DDD
		- we can take 6 boxes and 3 sticks and number of ways to put 3 sticks on 6 boxes =$^6C_{3}$
			- _ _ _ _ _ _
			- l l l
			- i.e. number of ways we can form partitions of 4
		- Why 3 sticks and 6 boxes =>
			- we need 4 partitions for each of object which can be obtained using 3 sticks
			- we need 6 boxes because
				- we need to use 3 boxes out of those to place sticks/partitions, 
				- and remaining 3 boxes are to be used to place objects
	- E.g: 3 flavours of juices available, 10 friends. How many variations of orders are possible
		- Let A, B, C be the flavours of juices available, and $n_{a}, n_{b}, n_{c}$ be number of juices of each flavour
		- $n_{a}+n_{b}+n_{c} = 10$
		- i.e 3 objects, select 10 with repetition allowed 
		- we need 3 partitions, thus 2 sticks, 
			- thus 2 boxes for 2 sticks
			- and remaining boxes should add up to 10 friends i.e. 12 boxes in total
			- ans: $^{12}C_{2}$
		- ![[Combination With repetition.png]]
- Thus, for $n$ different object s, to select $r$ with repetition allowed #boxes-sticks
	- We need $n$ partitions thus $n-1$ sticks
		- thus, $n-1$ boxes for $n-1$ sticks
		- and remaining boxes should add upto $r$ objects i.e. $r+(n-1)$ boxes in total
		- ans : $^{r+(n-1)}C_{n-1}$, 
			- i.e. no.of sticks needed ($n-1$) + no.of selections needed (r) = $n-1+r$
		- also since k-selections = k-rejection, $^{r+(n-1)}C_{r}$


- Questions:
	- How many ways 50 be represented as sum of 3 **whole numbers**
		- = 3 **identical** items, select 50 items, with repetition allowed
		- ans:
			- 3 numbers, thus 3 partitions, one for each number, thus 2 sticks
			- 2 boxes for 2 sticks
			- remaining boxes for 50 , thus 2+50 = 52 in total boxes
			- thus, ans = $^{52}C_{2}$
	- How many ways 50 be represented as sum of 3 **natural numbers**
		- = 3 items, select 50 items, with repetition allowed, given that **each object can be taken at least once**
			- ~~here, $^{52}C_{2}$ will be including 0, need to remove those where either of the 3 items is 0~~
				- ~~6 cases will have either of them 0~~
				- ~~thus ans = $^{52}C_{2}-6$ = 1320~~
			- another way to solve is from beginning only give 1 item to each and calculate for remaining
				- x+y+z=50, x>=1, y>=1, z>=1 thus, (x+1) + (y+1) + (z+1) = 50 i.e. x+y+z=47 and x>=0, y>=0, z>=0
				- i.e. we need to select 3 whole numbers that sum to give 47, 
					- as we are keeping 3 boxes reserved one for each of x, y and z
				- thus 3 partitions => 2 sticks, thus 2 boxes for 2 sticks, rest 47 boxes, thus 49 boxes in total, 
				- thus ans= $^{49}C_{2}$ = 1176
			- Another variation of this can be, x+y+z = 7, given that x>=0, y>=0 and z>=2
				- thus, we can solve for x+y+(z+2) = 7, i.e. x+y+z=5 where x>=0, y>=0 and z>=0
				- thus, 3 partitions, 2 sticks, 2 boxes for sticks, remaining 5 boxes thus 5+2 = 7 boxes in total,
				- ans: $^7C_{2}$
	- 100 **identical** candies, among 6 children 
		- 6 children, 6 partitions, 5 sticks
		- 5 boxes for 5 sticks
		- remaining boxes for 100, thus 100+5=105 in total
		- ans = $^{105}C_{5}$
	- 100 balls, 6 colours
		- $^{105}C_{5}$


- These statements are equivalent:
	- No.of combination/selection of $n$ objects, taken $r$ at a time with repetition
	- No.of ways r **identical objects** can be distributed among n distinct containers with repetition, given infinite supply of objects
	- No.of **non-negative integral** solutions to the system of equation
		- $x_{1}+x_{2}+\dots x_{n}=r$, where $x_i>=0$


### Permutation with Repetition
- n different type of objects, **arrange** r objects out of them, with repetition allowed
	- if repetition was not allowed
		- for first place we have $n$ options
		- for second place we have $n-1$ options
		- for third place we have $n-2$ options
		- .. for $r^{th}$ place we have $n-r+1$ options
		- thus, ans = $^nP_{r}$
	- here repetition allowed, so 
		- for first place we have $n$ options
		- for second place we have $n$ options
		- for third place we have $n$ options
		- ... for each place we have $n$ options
		- thus, ans = $n^r$

|                            | Order          | without repetition | with repetition                   |
| -------------------------- | -------------- | ------------------ | --------------------------------- |
| Permutation / arrangements | matters        | $^nP_{r}$          | $n^r$                             |
| Combination / selection    | doesn't matter | $^nC_{r}$          | $^{(n-1)+r}C_{n-1}=^{n-1+r}C_{r}$ |
